## [0.5.0] - 2026-10-27

### Added
- Optional LaTeX PDF export for Markdown files via the `md-to-lualatex` project.
- Browser print/export remains available without the optional LaTeX toolchain.

### Compatibility
- LaTeX export requires Pandoc, `latexmk`, and a LuaLaTeX toolchain, plus a configured `md-to-lualatex` checkout.
- Existing mdviewer workflows do not require the LaTeX dependencies.
