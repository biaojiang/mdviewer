## [0.4.3] - 2026-10-22

### Security
- Display raw HTML in Markdown as text and sandbox raw HTML/SVG responses.
- Confine document reads and directory listings using pinned roots and link-resistant opens.
- Reject descendant symlinks, including file and folder replacement races.

### Added
- Built-in Python filename/content search when fd or ripgrep is missing.
- Support Debian/Ubuntu fdfind executable names.
- Bound fallback regular-expression matching time with the regex dependency.

### Compatibility
- Normal Markdown, tables, footnotes, math, and images remain supported.
- Raw Markdown HTML and descendant symlinks are intentionally no longer active.
- External search tools retain their own regex/ignore rules; see README for fallback differences.
- Declare Flask >=2.0 and preserve Python 3.8-compatible build requirements.
